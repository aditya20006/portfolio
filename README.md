# Aditya Goyal Portfolio

A modern React portfolio website with a black theme, responsive layout, and dedicated sections for profile, skills, achievements, contact details, and featured projects.

## Features

- Black glass-style UI with a clean modern layout
- Responsive home and projects pages
- Sticky navigation with active page states
- Project showcase cards with tags and CTA buttons
- Built with React and React Router

## Tech Stack

- React
- React Router DOM
- CSS3
- Create React App

## Project Structure

```text
src/
  assets/
  components/
  pages/
  App.js
  App.css
```

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm start
```

3. Open the app in your browser:

```text
http://localhost:3000
```

## Build For Production

```bash
npm run build
```

## Notes

- The app uses `HashRouter`, which makes it easier to host on static platforms.
- The current project links in the Projects page can be replaced with your real GitHub repositories.
